# 背景图

IDE 背景图不是普通壁纸。壁纸追求画面饱满，IDE 背景图要主动让位给代码。

## 构图要求

- 宽高比 16:9 或接近窗口比例。月夜樱用的是 `1672×941`。
- **主体（人物 / 建筑 / 焦点）放在画面最右侧约 25%–35%**，因为右侧通常是 AI 面板或空白编辑区。
- 左侧 60%–70% 保持深色、低细节，给文件树和代码区留空间。
- 避开：图片自带文字、Logo、UI 元素、强烈高光、密集纹理、高对比条纹。
- 整体亮度压低。运行时还会叠一层渐变和半透明面板，原图偏亮的话最终会灰白发糊。

## 生成提示词要点

用 ImageGen 生成时，提示词里写清楚：

- 原创角色 / 场景，**不要指名现成动漫 IP、真实人物、品牌**
- 主体位于画面右侧，左侧留大面积低对比暗部
- 无文字、无水印、无界面元素
- 明确色调关键词，和主题配色对齐（accent 色最好在图里出现）

月夜樱的构图：原创成年女性角色、月夜赛博樱花工作室、人物在右、左侧低对比代码区、无文字无品牌。

用户自带图片也行，只要满足上面的构图要求。不满足的话（比如主体在正中间），换图比调 CSS 划算。

## 压缩

原图（PNG）留在 `assets/` 里备二次编辑，运行时只读压缩后的 WebP：

```bash
cwebp -q 82 -resize 1672 0 assets/<slug>-source.png -o assets/<slug>.webp
```

目标几百 KB。背景图会被整段 base64 编码塞进 CSS 变量注入，体积直接影响注入开销，超过 1MB 时 `validate.sh` 会警告。

没有 `cwebp`（`brew install webp`）时也可以直接用 PNG 或 JPG——注入器都支持，只是体积大很多。

## 和配色联调

背景图和主题配色是一起看的：

- 图定下来后，从图里取一个颜色当 accent，整体会更协调。
- 图偏冷就别配暖色 accent，反之亦然。
- 最后一定在实机上看，而不是只看图片本身——叠了渐变、半透明和毛玻璃之后，观感和原图差别很大。
